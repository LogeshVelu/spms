# Student Placement Management System (SPMS v4.0)
### Indian Institute of Technology Madras (IIT Madras)

An enterprise-grade campus placement automation platform featuring authoritative eligibility rule evaluation, multi-round interview progression, verifiable document vaults, and Super Admin institutional placement analytics.

---

## 🏛️ Architecture Overview

The system is engineered as a high-performance **Unified Full-Stack Application**:
- **Frontend SPA**: React 18, Vite 6, Tailwind CSS design tokens compiled via custom scanner (`build-css.js`).
- **Backend API**: Node.js (ES Modules), Express.js modular routing (`/api/v1`).
- **Data Layer**: SQLite with `better-sqlite3`, WAL mode enabled, foreign keys enforced, and re-entrant transaction isolation.
- **Unified Delivery**: A single Node process on port `5050` simultaneously powers the REST API and serves the production client bundle (`client/dist`).

## ⚡ Quick Start & Development

### 1. Start Platform (Full-Stack Dev Mode)
```bash
# Compiles Tailwind tokens, builds client assets, and starts server on http://localhost:5050
npm run dev
```

### 2. Run Only Backend Server
```bash
npm start
```

### 3. Rebuild Client Frontend
```bash
npm run build
```

### 4. Reseed Baseline Demonstration Data
```bash
npm run seed
```

## 🛡️ Key Platform Workflows

1. **Multi-Round Recruitment Pipeline**:
   - Round 1: Resume Screening & Verification
   - Round 2: Technical Interview Slot Scheduling
   - Round 3: Executive Interview & Culture Fit
   - Final Stage: Formal Placement Offer Issuance
2. **Authoritative Server-Side Rule Engine**:
   - Strict server-side verification of CGPA, standing arrears, and 10th/12th percentages before allowing application submission.
3. **Formal Offer Management**:
   - Once Round 3 is cleared, recruiter issues a customized offer with customizable company designation and annual CTC (LPA).
   - Generates an official IIT Madras placement letterhead delivered directly to the candidate portal.
4. **Institutional Analytics & Placed Directory**:
   - Live dashboard for the Placement Directorate showing verified unique placed students, departmental placement percentages, and a searchable candidate directory.
